Partwise adapted those images by cropping or resizing them, adding model-generated anomaly overlays, arranging comparison panels, and adding labels and results. **These adapted visual assets are shared under CC BY-NC-SA 4.0.** The original dataset files and fitted model artifacts are not included in the repository. Original Partwise source code is separately licensed under [MIT](../LICENSE). Charts created solely from evaluation summaries and other project text are separate from these dataset-derived image assets.

The dataset license limits commercial use. See the linked MVTec page and Creative Commons terms before reusing these visuals.
